# Marketing Analytics

A portfolio of marketing analytics projects focused on customer behavior, predictive modeling, and marketing performance analysis.

## Projects

### 1. Customer Lifetime Value Analysis

Analyzes customer purchasing behavior and estimates Customer Lifetime Value (CLV) using customer transaction data and probabilistic modeling.

**Skills:** Customer Analytics, CLV, Customer Segmentation, Predictive Analytics

📁 `Customer-Lifetime-Value-Analysis/`

---

### 2. Customer Churn Prediction with PySpark

Builds and evaluates machine learning models to predict customer churn using Apache Spark and PySpark.

**Skills:** Machine Learning, PySpark, Feature Engineering, Classification, Model Evaluation

📁 `Customer-Churn-Prediction-Spark/`

---

### 3. Marketing Mix Modeling with Google Meridian & SHAP

Evaluates marketing channel effectiveness using Bayesian Marketing Mix Modeling, ROI, marginal ROI, adstock, saturation analysis, SHAP explainability, and marketing budget scenario analysis.

**Skills:** Marketing Mix Modeling, Bayesian Analytics, ROI Analysis, SHAP, Budget Optimization

📁 `Marketing-Mix-Modeling-Meridian-SHAP/`
